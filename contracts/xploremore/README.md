# Vendored XploreMore contract

`problems.v1.openapi.json` is a byte-for-byte copy of XploreMore's
`contracts/api/problems.v1.openapi.json` (generated by
`uv run python -m xm_api.contract` there; last changed in XploreMore commit
`928333a`, sha256 `460e300379808ece1ec162cc671000e6f73f0cb1bd517a7d0d6ed928770e2adb`).

It is the consumer side of the contract test (ADR-0012): `tests/test_xploremore.py`
validates every mocked response payload against its component schemas and every
request's query parameters against its parameter schemas, so the client can't
drift from what the provider documents.

Rules inherited from the provider: additive changes only within v1. To update,
copy the file again, record the new commit and hash here, and run `uv run pytest`.

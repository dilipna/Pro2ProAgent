# Decision Desk

A handcrafted offline reference for a more deliberate agent-action review UI.
This is a quality target for ProToPro, **not a generated-output benchmark**.

Open `index.html` in a modern browser. All assets are local. If file-origin storage
is restricted, serve this folder with `python -m http.server --bind 127.0.0.1 3199`.
No account, API, build step, model, email service or external library is needed.

Inspect five clearly labeled fictional proposals. Enter a reason, approve or decline
locally, search/filter, and export the trail. No tool is executed. Refresh preserves
reviews; duplicate decisions are prevented. Start empty clears this reference's
workspace and stays empty after refresh; Reset examples restores illustrative data.
These controls affect only `decision-desk.reference.v1` in this browser.

See `docs/prototype-quality.md` for the optional browser-review tool and scenarios.
Adapt the thinking and interaction patterns to other products instead of copying
this palette into every generated prototype.
